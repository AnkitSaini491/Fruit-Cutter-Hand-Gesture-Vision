# 🍎 Fruit Cutter - Hand Gesture Vision

A real-time computer vision based Fruit Cutter game built using Python,
OpenCV and MediaPipe.

The project uses webcam-based hand tracking to detect the user's index
finger movement and allows the player to virtually cut fruits on the screen.

## 🎮 Features

- ✋ Real-time hand tracking
- 👆 Index finger tracking
- 🍎 Virtual fruit generation
- 🔪 Gesture-based fruit cutting
- 🏆 Score system
- ❤️ Lives system
- ⏱️ Timer
- 💥 Cutting trail effect
- 🔄 Restart game
- 📷 Live webcam processing

## 🛠️ Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
